# Mythic TCG

A clean Godot 4.7 project for a mythology trading card game.

Only the Godot AI addon was copied from H:/kurukshetra. No game content was copied.
Open project.godot with Godot 4.7.1. The Godot AI editor plugin is enabled.

Card art, frames, rules text, and runtime card state will be separate resources.
Initial scope: Greek and Norse playable cards, followed by Egyptian and Roman.

Godot AI addon upgraded to v4.2.3 to match the configured MCP server (HTTP 8102, WebSocket 8103).
